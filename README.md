# Stigpass

Planera träningspass för cykelgruppen, spara övningar och banor, och dela dagens pass med ledarna i WhatsApp eller Messenger.

Appen hämtas gratis från GitHub Pages. Allt du lägger in sparas **bara i telefonen**. Det finns ingen inloggning, ingen server och ingen spårning, och appen fungerar utan täckning.

---

## Lägga upp appen på GitHub

1. Logga in på [github.com](https://github.com) och skapa ett repository som heter `stigpass` (**Public**).
2. Tryck **Add file → Upload files**. Packa upp `stigpass-lokal.zip`, öppna mappen och dra in **allt** som ligger i den, även mapparna `fonts` och `icons`. Tryck **Commit changes**.
3. **Settings → Pages**: välj **Deploy from a branch**, **main** och **/ (root)**. Tryck **Save**.
4. Efter 1–2 minuter finns appen på `https://dittnamn.github.io/stigpass/`.

## Installera på telefonen

5. Öppna adressen i **Safari** (iPhone) eller **Chrome** (Android).
6. iPhone: tryck **Dela → Lägg till på hemskärmen**.
   Android: tryck **⋮ → Installera app** eller **Lägg till på startskärmen**.
7. **Öppna appen från ikonen på hemskärmen** och använd den därifrån. På iPhone har hemskärmsappen en egen lagring, skild från Safari.

## Flytta in dina pass

8. I appen: tryck på menyn uppe till höger → **Importera från fil** → välj `stigpass-data.json`.
   **Ladda inte upp den filen till GitHub.** Där blir allt offentligt.

## Säkerhetskopia

Datan finns bara i telefonen. Den försvinner om du tar bort appen från hemskärmen, rensar webbplatsdata eller byter telefon.

- Tryck på menyn → **Spara säkerhetskopia** och spara filen i till exempel Filer, iCloud Drive eller Google Drive.
- Appen påminner dig om det har gått mer än en månad sedan sist.
- Ny telefon: installera appen och välj **Importera från fil**.

## Uppdatera appen

Får du nya filer: GitHub → **Add file → Upload files**, dra in dem och tryck **Commit changes**. Filer med samma namn ersätts. Din data i telefonen påverkas inte. Stäng appen helt och öppna den igen för att få den nya versionen.
